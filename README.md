# PWA Allergènes – restauration scolaire

Version initiale générée à partir du fichier Excel `allergenes_restauration_scolaire.xlsx`.

## Fonctionnalités
- PWA installable
- fonctionnement hors connexion après première ouverture
- base locale navigateur (localStorage)
- 123 aliments importés depuis la feuille source lorsque lisibles
- ajout / modification / suppression d'aliments
- création de recettes par sélection d'ingrédients
- calcul automatique des 14 allergènes
- création d'une semaine de menus
- calcul des allergènes par jour
- export/import JSON de sauvegarde
- pas d'impression

## GitHub Pages
1. Créer un dépôt GitHub.
2. Copier tous les fichiers de ce dossier à la racine.
3. Settings → Pages → Deploy from branch → `main` / root.
4. Ouvrir l'URL GitHub Pages.
